One line about office life: a daily standup that runs so long it swallows the whole day. The program writes the single line to `entry.txt` (UTF-8, 92 characters, no trailing newline).

> Our daily standup ran so long that by the time I said what I did yesterday, it was tomorrow.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/office-joke-suzy-out python3 main.py
```
